# Folder: voting-frontend

This is the React (Vite) frontend for the voting UI.

## What you’ll find here

- src/ — pages, components, and routing
- vite.config.js — build config
- package.json — scripts and dependencies

## Local dev quick start

```sh
cd voting-frontend
npm install
npm run dev
```
